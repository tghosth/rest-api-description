# GitHub Issues API - Read-Only OpenAPI Schema

This directory contains a trimmed-down version of the GitHub REST API OpenAPI schema that includes **only** issue-related endpoints for reading and searching.

## File: `api.github.com.issues.json`

This file is a subset of the full `api.github.com.json` schema, containing only GET operations related to GitHub Issues.

### What's Included

The schema includes **22 endpoints** for accessing GitHub Issues data:

#### Global Issue Endpoints
- `GET /issues` - List issues assigned to the authenticated user
- `GET /user/issues` - List user account issues
- `GET /search/issues` - Search issues and pull requests

#### Organization Issue Endpoints
- `GET /orgs/{org}/issues` - List organization issues
- `GET /orgs/{org}/issue-types` - List issue types for an organization

#### Repository Issue Endpoints
- `GET /repos/{owner}/{repo}/issues` - List repository issues
- `GET /repos/{owner}/{repo}/issues/{issue_number}` - Get an issue
- `GET /repos/{owner}/{repo}/issues/{issue_number}/comments` - List issue comments
- `GET /repos/{owner}/{repo}/issues/{issue_number}/events` - List issue events
- `GET /repos/{owner}/{repo}/issues/{issue_number}/labels` - List labels for an issue
- `GET /repos/{owner}/{repo}/issues/{issue_number}/reactions` - List reactions for an issue
- `GET /repos/{owner}/{repo}/issues/{issue_number}/timeline` - List timeline events for an issue
- `GET /repos/{owner}/{repo}/issues/{issue_number}/assignees/{assignee}` - Check if a user is assigned to an issue
- `GET /repos/{owner}/{repo}/issues/{issue_number}/parent` - Get issue parent
- `GET /repos/{owner}/{repo}/issues/{issue_number}/sub_issues` - List sub-issues
- `GET /repos/{owner}/{repo}/issues/{issue_number}/dependencies/blocked_by` - List issues blocking this issue
- `GET /repos/{owner}/{repo}/issues/{issue_number}/dependencies/blocking` - List issues blocked by this issue

#### Issue Comments Endpoints
- `GET /repos/{owner}/{repo}/issues/comments` - List issue comments for a repository
- `GET /repos/{owner}/{repo}/issues/comments/{comment_id}` - Get an issue comment
- `GET /repos/{owner}/{repo}/issues/comments/{comment_id}/reactions` - List reactions for an issue comment

#### Issue Events Endpoints
- `GET /repos/{owner}/{repo}/issues/events` - List issue events for a repository
- `GET /repos/{owner}/{repo}/issues/events/{event_id}` - Get an issue event

### What's NOT Included

This schema **excludes** all endpoints that:
- Create, update, or delete issues (POST, PATCH, PUT, DELETE methods)
- Modify issue properties (assignees, labels, milestones, etc.)
- Create or modify issue comments
- Lock or unlock issues
- Add or remove reactions
