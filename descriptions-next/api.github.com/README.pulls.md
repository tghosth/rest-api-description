# GitHub Pull Requests API - Read-Only OpenAPI Schema

This directory contains a trimmed-down version of the GitHub REST API OpenAPI schema that includes **only** pull request related endpoints for reading and searching.

## File: `api.github.com.pulls.json`

This file is a subset of the full `api.github.com.json` schema, containing only GET operations related to GitHub Pull Requests.

### What's Included

The schema includes **15 endpoints** for accessing GitHub Pull Requests data:

#### Pull Request Endpoints
- `GET /repos/{owner}/{repo}/pulls` - List pull requests in a repository
- `GET /repos/{owner}/{repo}/pulls/{pull_number}` - Get a pull request
- `GET /repos/{owner}/{repo}/pulls/{pull_number}/commits` - List commits on a pull request
- `GET /repos/{owner}/{repo}/pulls/{pull_number}/files` - List files changed in a pull request
- `GET /repos/{owner}/{repo}/pulls/{pull_number}/merge` - Check if a pull request has been merged
- `GET /repos/{owner}/{repo}/pulls/{pull_number}/reviews` - List reviews on a pull request
- `GET /repos/{owner}/{repo}/pulls/{pull_number}/reviews/{review_id}` - Get a review for a pull request
- `GET /repos/{owner}/{repo}/pulls/{pull_number}/reviews/{review_id}/comments` - List comments for a pull request review
- `GET /repos/{owner}/{repo}/pulls/{pull_number}/comments` - List review comments on a pull request
- `GET /repos/{owner}/{repo}/pulls/{pull_number}/requested_reviewers` - List requested reviewers for a pull request
- `GET /repos/{owner}/{repo}/pulls/comments` - List review comments in a repository
- `GET /repos/{owner}/{repo}/pulls/comments/{comment_id}` - Get a review comment for a pull request
- `GET /repos/{owner}/{repo}/commits/{commit_sha}/pulls` - List pull requests associated with a commit
- `GET /repos/{owner}/{repo}/branches/{branch}/protection/required_pull_request_reviews` - Get pull request review protection
- `GET /search/issues` - Search for issues and pull requests (includes PRs since they are considered issues in GitHub's API)

### What's NOT Included

This schema **excludes** all endpoints that:
- Create, update, or delete pull requests (POST, PATCH, PUT, DELETE methods)
- Modify PR properties (assignees, labels, milestones, etc.)
- Create or modify review comments
- Approve, request changes, or merge pull requests
- Update branch protection settings
- Reaction endpoints for PR comments

### ChatGPT Action Compatibility

This schema is optimized for use as a ChatGPT action:
- All operationIds use camelCase format (e.g., `pullsList`, `pullsGet`, `pullsListReviews`)
- OperationIds are valid identifiers containing only alphanumeric characters
- No special characters (slashes, hyphens) that might cause issues with tool ID mapping
- All operation descriptions are truncated to 300 characters maximum (ChatGPT action limit)
- All parameter references (`$ref`) have been inlined with explicit `name` fields

### Generation

This schema was generated by:
1. Extracting all paths containing "pull" in the path name from the full schema
2. Including the search endpoint (which searches both issues and PRs)
3. Keeping only GET operations (read-only)
4. Recursively resolving all component references (schemas, parameters, responses, etc.)
5. Converting operationIds to camelCase for tool compatibility (e.g., ChatGPT actions)
6. Truncating descriptions to 300 characters maximum
7. Inlining all parameter references with explicit names
